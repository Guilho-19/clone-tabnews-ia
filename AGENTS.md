# AGENTS.md

Este arquivo dá contexto aos agentes de IA que trabalham neste repositório.

## Sobre o projeto

Clone do [TabNews](https://tabnews.com.br) feito para o curso [curso.dev](https://curso.dev), construído com a ajuda de agentes de IA.

## Stack

- **Next.js 16** com **App Router** (diretório `app/`)
- **React 19**
- **JavaScript** puro (sem TypeScript)

## Comandos

- `npm run dev` — sobe o servidor de desenvolvimento

## Convenções

- Idioma do conteúdo e da interface: português (pt-BR)
